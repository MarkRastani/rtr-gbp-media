# rtr-gbp-media

Image host for Rooftop Relief Google Business Profile posts.

Images in `images/` are referenced by GBP posts via permanent raw URLs:

```
https://raw.githubusercontent.com/MarkRastani/rtr-gbp-media/main/images/<filename>.jpg
```

## Rules

- **JPEG preferred**, quality ~85, under 5 MB (GBP limit; 10 KB minimum)
- Minimum 250×250 px, aspect ratio between 0.5 and 2.0
- Descriptive kebab-case filenames (`chimney-flashing-cincinnati.jpg`)
- **Never delete or rename** a file that a published post references — URLs must stay live forever
